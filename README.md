# Chude9.github
Chủ đề 9: Kiểm thử tự động trên nền web bằng Robot framework

# 1. Giới thiệu
Đây là dự án của nhóm thực hiện nhằm nghiên cứu và xây dựng hệ thống
kiểm thử tự động trên nền web sử dụng Robot Framework.

# 2. Mục tiêu
- Tìm hiểu về kiểm thử tự động trên nền web.
- Làm quen với Robot Framework.
- Xây dựng các test case tự động.
- Thực hiện kiểm thử các chức năng của ứng dụng web.
- Quản lý mã nguồn và làm việc nhóm thông qua Git và GitHub.

# 3. Công nghệ sử dụng
- Python
- Robot Framework
- Browser Library
- Playwright
- Git
- GitHub

# 4. Phạm vi dự án
Dự án tập trung vào việc xây dựng và thực hiện các test case tự động
cho trang web lms.hpu2.edu.vn
Các chức năng kiểm thử dự kiến bao gồm:
- Đăng nhập
- Đăng ký
- Tin nhắn
